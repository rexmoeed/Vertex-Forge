## 2024-05-18 - [Debounce and Memoize Filter in AIProviderHubView]
**Learning:** In Vertex Forge React components, heavy data transformations, list filtering, and methods that synchronously read from `localStorage` (like `AIProviderService.filterModels`) should always be wrapped in `useMemo` to prevent severe UI lag on renders. Moreover, when filtering based on user input, simply wrapping the filter function in `useMemo` is not enough to prevent UI lag on keystrokes if the query state is a dependency. To properly prevent keystroke lag, the search input or the filtering state updates must be debounced.
**Action:** When implementing filtering inside a React component, ensure the query parameter is debounced (using a state and `useEffect` with `setTimeout`) and the filtering process itself is memoized using `useMemo` that depends on the debounced query, particularly when interacting with synchronous data sources or large datasets.
