## 2026-11-09 - AIProviderHubView Optimization
**Learning:** In React components dealing with search inputs that drive heavy filtering or read from `localStorage` synchronously (like `AIProviderService.filterModels`), it is not enough to just memoize the function. The search query state itself updates on every keystroke, causing the component to re-render and execute the heavy memoized function repeatedly, which causes severe UI lag.
**Action:** When filtering logic is heavy or reads from `localStorage`, debounce the query state used in the filtering function's dependencies. Additionally, when testing components with debounced states in JSDOM, be sure to use `vi.useFakeTimers()` in the test setup (`beforeEach`) to prevent async timers from leaking across tests and causing global suite crashes with 'ReferenceError: window is not defined'.
